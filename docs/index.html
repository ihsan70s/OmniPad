OmniPad

Jadikan HP kamu remote untuk PC Windows atau Google TV di jaringan lokal.

Jalankan receiver di perangkat tujuan, pindai kode QR, lalu tekan Hubungkan di browser HP. OmniPad masih dalam tahap prototipe dengan target Windows dan Google TV dengan Android TV OS 14.

Buka panduan di GitHub

Kontrol dari browser HP

  • Windows. Gunakan trackpad, keyboard, tombol media, atau kontrol game virtual. Mode mirroring bisa menampilkan monitor PC di HP.
  • Google TV. Gunakan tombol arah, OK, Kembali, Home, dan kontrol media yang didukung perangkat.

Coba tampilannya

Unduh ZIP dari GitHub, ekstrak, lalu buka Preview.html untuk mencoba antarmuka tanpa mengirim perintah ke perangkat.
