Cara menggunakan remote
  • Mouse: ketuk satu jari untuk klik kiri; ketuk dua jari untuk klik kanan.
  • Geser dua jari untuk menggulir. Tahan Klik kiri lalu geser untuk menyeret.
  • Untuk mengetik, pilih kolom di PC, buka Ketik ke PC, lalu tekan Kirim teks.
  • Jika tombol terasa tertahan, tekan Lepaskan tombol.
  • Saat berpindah aplikasi di HP, koneksi akan diputus. Tekan Hubungkan untuk memakai remote lagi.
  • Untuk menghentikan akses sepenuhnya, tutup OmniPad di PC.
